Start a fresh `worker`, `scout` or `goldfish` subagent Session or start/reuse one persistent `spec` or `standards` reviewer Session under this Session. `role` is `spec`, `standards`, `worker`, `scout`, or `goldfish`. For `spec` and `standards`, supply the local `ticketPath` and `startingPoint` captured before implementation (rejects `tier`); include uncommitted changes, start both roles independently after each ticket, and pause parent edits until reports arrive (repeated calls reuse the same reviewer, even for another ticket; no Runs or automatic fix loop). For `worker` and `scout`, supply `text`, optional `title`, and optional `tier` (`smol`, `mid`, or `top`; defaults to `mid`) (`scout` is read-only; each call opens a fresh parallel Session; omit `ticketPath` and `startingPoint`). `goldfish` is a read-only, stateless, one-shot reviewer: supply `persona` (the id of an installed persona; an unknown id is rejected with the available ids), `text` (the review request and the paths it needs), optional `title` (defaults to `Goldfish (<persona>)`), and optional `tier` (defaults to `mid`). Each call opens a fresh Session that sees none of this conversation. It cannot be steered or prompted again, and it is stopped automatically once its report arrives, whether it submitted or ended its turn without one (the transcript stays readable); for follow-up, spawn a new goldfish.

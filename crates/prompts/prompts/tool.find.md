Locate files, symbols and line ranges implementing a concept or behavior. `query` names the concept and `grep_keywords` adds keywords to match, as a list. `path` scopes the search, and `mode` is `search` (lexical ranking and seen lines), `outline`, `architecture` (graph summary when the graph server is up, local file list otherwise) or `trace` (graph call graph for an unpathed symbol, local symbol search when `path` is given). `direction` is `inbound` or `outbound` and `depth` is 1-5, both for `trace`. `limit` caps the hits.

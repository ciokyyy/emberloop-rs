The ember skill pack is installed: `ember-flow` routes work through grill (shared understanding and recorded decisions), design, audit (fresh-context goldfish find the holes), slice (vertical tickets), build (test first, root cause first, evidence first) and review (spec and standards reviewers).

Before your first response in a Session, and whenever a task turns into real work, read `el://skills/ember-flow/SKILL.md` and follow it. It names the stage skill to read next, as `el://skills/ember-<stage>/SKILL.md`; resolve any path a skill mentions relative to its own folder. A skill's scripts run through `bash` with their absolute path, because the shell starts at the project root.

A direct user instruction wins: do not run a grill, a design gate or any other ceremony on a one-line change the user asked for plainly.

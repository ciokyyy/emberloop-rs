Search the Project tree for a regular expression in `pattern`. `path` narrows the scope and `glob` filters file names. `case_insensitive`, `context` and `max_results` tune the answer, and `output_mode` picks `content` (default), `files`, `count` or `json`, one object per match with its path, line number and raw text; a script that needs every match compares the row count with `max_results`. `context` applies to `content` only. Inside `execute` the array stays whole; a top-level call over the spill threshold replaces it with a `ctx:<handle>`, so call `grep` from `execute` or narrow `path` and `max_results` when you need every row. Escape regex metacharacters to match a literal string. `.gitignore` is respected.

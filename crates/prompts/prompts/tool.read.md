Read a file, a URL, a skill or internal docs. `path` is any path your account can read: a leading ~ expands from HOME, and a relative path joins the Project root. A goldfish Session reads only the Project, the skill roots and its own Session directory. An `http://`, `https://` or `www.` target is fetched as Markdown instead of read from disk; `el://skills/<name>` reads a skill, and its header names the root-named path (`el://skills/global/<name>/SKILL.md` or `el://skills/project/<name>/SKILL.md`) that `edit` and `write` take (`el://skills` indexes the skill modules and names the skills no module holds, never their bodies); `el://docs/<topic>` reads configuration docs (`el://docs` lists topics); `ctx:<handle>` pages output another tool spilled. A normal read returns the first 300 lines: append `:raw` to the path for the whole file, or page with `offset` and `limit`. `plain` returns a file or `ctx:<handle>` as raw lines, with no tag header and no line numbers, and those lines never authorize an anchored `edit`. A skill or doc always reads whole. Plain text only, 2 MiB cap, numbered lines.

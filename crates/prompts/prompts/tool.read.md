Read a file, a URL or a skill. `path` is resolved inside the Project root; an `http://`, `https://` or `www.` target is fetched as Markdown instead of read from disk; `el://skills/<name>` reads a skill (`el://skills` lists all); `ctx:<handle>` pages output another tool spilled. A plain read returns the first 300 lines: append `:raw` to the path for the whole file, or page with `offset` and `limit`. A skill always reads whole. Plain text only, 2 MiB cap, numbered lines.

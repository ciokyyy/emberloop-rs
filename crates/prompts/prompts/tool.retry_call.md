Retry a failed call recorded as `[failed call #N]` without retyping large prompts. Pass the integer `id` from the failure message, optional `set` top-level argument overrides (pass JSON null to remove a key), and optional `patches` array of `{ "old": "...", "new": "..." }` exact-once string replacements applied across string values after `set`. Rejects missing or ambiguous patches cleanly; if the retried call fails again, a new `#N` is recorded.

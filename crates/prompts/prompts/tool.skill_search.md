Search skills by words. Ranks each skill's name, module name, description, headings and opening text with BM25 over every global and project skill. Each hit gives the name, its module in brackets, origin, description and the absolute SKILL.md path; read that path to load the skill. A query that is a module name lists that module's skills first and says what the module covers. Use it when the catalog lists no skill that fits. `query` is one or more words; `limit` caps the hits (default 5, max 20).

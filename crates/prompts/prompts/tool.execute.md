`execute` runs Python in a persistent REPL: variables, imports and functions survive between calls. `code` is required unless `reset` is set; `reset` alone answers `[repl reset]` and clears the state first. `timeout` is in seconds, default 120, max 600; a stuck turn tears the interpreter down and the next call starts fresh. `background: true` runs the script detached instead (no state, no auto-return) and answers with a handle the `background` tool reads, waits on and stops.

One call runs at a time: a concurrent call fails with `another execute call is running`. A trailing expression prints its repr, capped at 2,048 bytes; `None` prints nothing, so use print for output. `[vars: ...]` lists up to 8 live globals. Tools are pre-injected as `tools.read`, `tools.grep`, `tools.edit`, `tools.write`, `tools.bash`, `tools.background`, `tools.find`, `tools.websearch` and `tools.call(name, **kwargs)`, with positional or keyword arguments: `tools.read('a.rs')`. One `tools.edit(input=...)` call patches one or more files; never call it through `tools.parallel`. A failing call raises `tools.ToolError`. Execute cannot call itself inside a script.

`tools.parallel([(name, kwargs), ...], max_workers=4, strict=False)` runs at most 16 calls at once, answers in order, and `strict=True` raises the first failure; edit and write are refused because two writes can race. `tools.save(name, code, description)` with `tools.run(name, **args)` keeps a script; `tools.store(key, value)` with `tools.load(key)` keeps JSON for this Session. Each call is saved as `[saved exec #N]`: `tools.rerun(N, patches=[(old, new)])` reruns a patched copy, `tools.exec_source(N)` reads it. One script may make 500 tool calls.

Batch: loop over many items, or run independent calls together with `tools.parallel`, so the batch costs one model turn. Filter before you print, and prefer a native tool call over a one-call script.

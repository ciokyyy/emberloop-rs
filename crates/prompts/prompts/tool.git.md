Read-only git inspection of the Project. `args` is a list of git arguments starting with the subcommand, run as `git -C <root> --no-pager`: diff, log, show, blame, status, ls-files, grep, rev-parse, merge-base, cat-file, and branch or tag listing (which needs a list flag). Writing, executing and configuring flags are refused, such as -c, -O, --output or --ext-diff. `timeout` is in seconds, default 120, max 600.

Create and update skills: your procedural memory for recurring tasks. The call is an operations array `ops` (a single edit is a list of one). It applies atomically: any failure rolls every touched skill back. Each op has `op` and `name`. `create` writes a full SKILL.md; it lands in the global skills directory unless `scope` is `global`, or in the project when `scope` is `project`; origin is always agent; it must come before that skill's other ops. `patch` makes a targeted fix with `old_string` and `new_string` (preferred); `content` alone replaces the whole file, so read it with read first. `write_file` and `remove_file` change supporting files under references/, templates/, scripts/ or assets/, named by `path`. `replace_all` lets a patch change every match. Only agent-origin skills change; human and downloaded skills are never changed here. A patch or write needs the file read first in this session. Description: max 1024 chars, 'Use when <trigger>. <behavior>.', never the category name. Write lessons, not logs: imperative rule + why, no PR numbers/dates/incident narration, one rule per lesson, references/ named by topic (extend before adding).

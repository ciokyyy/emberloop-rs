# Ticket 10: SPA UI (SvelteKit, Tailwind v4, shadcn-svelte)

## Goal

Web UI copied and cut down from `emberloop-web/web/src`: Projects sidebar, Sessions list, chat feed with flat tool rows and hue glyphs, composer with drag-and-drop images, Settings tab, embedded via rust-embed. Blocked by ticket 04.

## Status

Complete; `npm run check`, `npm test` and `npm run build` pass in `web/`.

- [x] SvelteKit static SPA (SSR off), Tailwind CSS v4, shadcn-svelte-style local components over `bits-ui`.
- [x] Projects and Sessions sidebar with status dots, new Session dialog, rename and delete.
- [x] Feed: Markdown rows, flat tool rows with hue glyphs, expandable bodies, compression, steer, notice and error rows.
- [x] Composer: multiline, Enter sends, paste/drop/pick images, 10 MB and 5-image limits, thumbnails, Stop and steer while working.
- [x] Settings: proxy compression, Ponytail level, disabled Subagents cards.
- [x] Typed `fetch` client and SSE replay from `/api/sessions/:id/events?after=`.
- [x] Embedded by the daemon via `rust-embed`; OpenAPI types are generated by `scripts/check`.

Includes the frontend efficiency rules of spec decision J: first load is meta plus about 50 tail events, virtualized feed, older pages on scroll up with scroll held, client state for the current and previous two Sessions only.
